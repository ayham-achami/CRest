## Требования

- iOS 11+
- Swift 5.0

## Установка

### Swift Package Manager

В XCode добавьте пакет - File> Swift Packages> Add Package Dependency.

```swift
dependencies: [
    .package(name: "CRest", url: "https://github.com/ayham-achami/CRest.git", from: "1.0.0")
]
```
